# 召回指标字典（V4/V5）

> 状态：草稿，待业务确认后更新。

## 一、基础概念

| 名称 | 定义 |
|---|---|
| VIP 等级 | 公司内部定义的用户等级，本文关注 V4、V5 |
| 召回用户 | VIP 等级为 V4/V5，且距上次存款时间**超过 30 天**未存款的用户 |
| 成功召回 | 召回用户之后发生**一次存款**，即记为成功召回 |
| 召回时间 | 成功召回对应的那次存款的时间 |
| 归因窗口 | 从召回时间起的 **30 天**（含第 0 天，但只统计召回时间之后的行为） |

## 二、判定规则

1. **进入召回**：用户等级为 V4/V5，且当前时间与其上次存款时间的间隔 > 30 天。
2. **成功召回**：处于召回状态的用户，发生一次存款，即记录召回时间。
3. **再次召回**：成功召回后，若再次满足"距上次存款 > 30 天"，则再次进入召回状态，并可再次被成功召回。每次召回的归因窗口独立计算。
4. **第 0 天规则**：归因窗口内，只统计召回时间**之后**产生的投注，召回时间之前的投注不计入。

## 三、核心指标

| 指标 | 口径 | 统计范围 |
|---|---|---|
| 召回人数 | 进入召回状态的用户数（去重） | 按月、按 VIP 等级 |
| 成功召回人数 | 完成召回存款的用户数（去重） | 同上 |
| 召回率 | 成功召回人数 ÷ 召回人数 | 同上 |
| 窗口投注额 | 召回时间起 30 天内，召回时间之后的投注额合计 | 按召回次数汇总 |
| 人均窗口投注额 | 窗口投注额 ÷ 成功召回人数 | 同上 |

## 四、示例

| 用户 | 事件 | 结果 |
|---|---|---|
| A | 第 0 天 10:00 存款（成功召回），第 0 天 09:00 投注 100 | 窗口投注额 = 0（投注在存款之前，不计） |
| A | 第 0 天 10:00 存款，第 0 天 12:00 投注 100，第 10 天投注 200 | 窗口投注额 = 300 |
| A | 第 0 天后，第 31 天起未存款超过 30 天 | 再次进入召回状态，可再次成功召回 |
